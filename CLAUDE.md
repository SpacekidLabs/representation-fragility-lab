# CLAUDE.md

## Rule: open a ticket before changing anything

Every change to this repository must be tracked by a GitHub issue that exists **before** the change is made.

1. Before editing, creating or deleting any file, open a GitHub issue on
   `SpacekidLabs/representation-fragility-lab` describing the change (goal, scope, done when).
   If the change continues work from a closed issue, reopen that issue instead.
2. Do not start editing until the issue exists.
3. Reference the issue in every commit message: `#N` for intermediate commits,
   `closes #N` for the commit that completes it.
4. If the scope changes while working, update the issue first.

## Project direction

The goal of the project is in [docs/VISION.md](docs/VISION.md): look at a signal through many
representations, compare where they disagree, and learn from the disagreement. Roadmap issues
are titled "Roadmap N: ..." on GitHub.
